Requirements for the Calculator before considered complete

1. Addition - Must be able to add 2 integers
2. Subtraction - Must be able to subtract 1 integer from another
3. Multiplication - Must be able to multiple 2 integers
4. Divisions - Must be able to divide an integer by a non-zero integer
5. Must be able to display the result into the terminal

2 Example inputs and expected output

  Input   |  Output
__________________________
   1+7    |    8
  50/10   |    5
